# Module Outline: Position and Deliver the Workshop

## Brief Overview

This module introduces the OpenShift Ops Day Roadshow, explains its value propositions and delivery formats, and covers the end-to-end process of delivering the workshop to customers — from positioning and scheduling through module delivery, lab provisioning, and presenter preparation.

## Audience and Time

- **Target personas:** Solution architects, specialist solution architects, adoption architects, technical account managers, sales specialists
- **Prerequisites for this module:** Familiarity with `oc`/`kubectl` CLI and OpenShift web console
- **Estimated duration:** 25 minutes

## Learning Objectives

- Learn about the OpenShift Ops Day Roadshow's structure, content, value propositions, and delivery formats
- Deliver a workshop module including supporting materials, lab setup, live walkthroughs and student work time

## Detailed Steps

### What is the OpenShift Roadshow?

1. Describe the Roadshow as a collection of interactive activities showcasing OpenShift's features and value propositions.
2. Describe the Roadshow as a ready-to-run environment for customers to familiarize themselves with OpenShift features.
3. Explain the Roadshow's relationship to other Red Hat content and enablement programs.

### Why is the OpenShift Roadshow useful?

4. Explain how the Roadshow makes potential customers aware of OpenShift's value propositions.
5. Explain how the Roadshow enables existing customers to fully use OpenShift's features.

### How to position the OpenShift Roadshow for customers

6. Describe how to propose the workshop via the account team
7. Explain how to scope content and duration for the engagement
8. Describe how to secure presenters and schedule delivery dates

### How to deliver the workshop

9. Describe how to run a one-day workshop with all content for a customer.
10. Describe how to run a regional event for multiple customers.
11. Describe how to run several one-hour sessions on individual modules for a customer.

### How to deliver a module

12. Review the supporting materials available for each module.
13. Describe the live walkthrough and discussion phase.
14. Describe the independent student work time phase.

### How to prepare and handle the lab environments

15. Explain how to request and provision environments for many users.
16. Describe what the lab environment provides to users.
17. Identify known issues that arise and how to troubleshoot them.

### How a presenter should prepare

18. Explain the process: request an environment and work through the content.

## Key Takeaways

- The Roadshow is a flexible, modular workshop for showcasing OpenShift to potential and existing customers.
- Three positioning options give presenters flexibility: full-day workshop, regional event, or individual module sessions.
- Every module follows the same delivery pattern: supporting materials, live walkthrough, and student work time.
- Presenters must prepare by working through the content in a real environment before delivering to customers.

## Infrastructure Notes

No cluster access is required for this module. All content is informational and delivered through the Showroom interface.
