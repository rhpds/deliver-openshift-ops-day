# Module Outline: Overview of All Modules

## Brief Overview

This module provides a comprehensive walkthrough of all 18 modules in the OpenShift Ops Day Roadshow. For each module, participants learn the topic background, the prerequisite knowledge a presenter needs, and the key content covered. This equips presenters to select the right modules for a given audience and to prepare for delivery.

## Audience and Time

- **Target personas:** Solution architects, specialist solution architects, adoption architects, technical account managers, sales specialists
- **Prerequisites for this module:** Completion of Modules 1-2 (understanding of Roadshow structure and delivery workflow)
- **Estimated duration:** 20 minutes

## Learning Objectives

- Describe the content and background required for each of the 18 Roadshow modules
- Identify which modules align with common customer priorities (operations, security, networking, storage, observability, application management)
- Assess which modules are appropriate for a given customer scenario based on topic coverage and prerequisites

## Detailed Steps

1. Review the complete list of 18 Roadshow modules grouped by topic area.
2. For each module in the core operations group, read the content summary and the background knowledge a presenter needs.
3. For each module in the security, networking, and storage group, read the content summary and the background knowledge a presenter needs.
4. For each module in the observability and application management group, read the content summary and the background knowledge a presenter needs.
5. Identify which modules address common customer priorities and note any dependencies between modules.
6. Using a provided customer scenario, select an appropriate subset of modules and justify the selection.
7. Answer the checkpoint questions to confirm understanding of the full module catalog and selection criteria.

## Key Takeaways

- The 18 modules span a wide range of Day 2 operations topics; presenters do not need to deliver all of them at once.
- Understanding the full module catalog helps presenters recommend the right sessions for a given customer's needs.
- Each module has specific background knowledge requirements; presenters should assess their own readiness before committing to deliver a module.
- Module selection should be driven by the customer's operational maturity and stated priorities.
