# Module Outline: Position the Workshop

## Brief Overview

This module introduces the OpenShift Roadshow, explains why it is useful for customers, and covers how to position it for different engagement scenarios.

## Audience and Time

- **Target personas:** Solution architects, specialist solution architects, adoption architects, technical account managers, sales specialists
- **Prerequisites for this module:** None beyond general OpenShift awareness
- **Estimated duration:** 20 minutes

## Learning Objectives

- Describe what the OpenShift Roadshow is and how it relates to other Red Hat content
- Explain why the Roadshow is useful for potential and existing customers
- Position the Roadshow for different customer engagement scenarios

## Detailed Steps

### What is the OpenShift Roadshow?

1. Describe the Roadshow as a collection of interactive activities showcasing OpenShift's features and value propositions.
2. Describe the Roadshow as a ready-to-run environment for customers to familiarize themselves with OpenShift features.
3. Explain the Roadshow's relationship to other Red Hat content and enablement programs.

### Why is the OpenShift Roadshow useful?

4. Explain how the Roadshow makes potential customers aware of OpenShift's value propositions.
5. Explain how the Roadshow enables existing customers to fully use OpenShift's features.

### How to position the OpenShift Roadshow

6. Describe how to run a one-day workshop with all content for a customer.
7. Describe how to run a regional event for multiple customers.
8. Describe how to run several one-hour sessions on individual modules for a customer.

## Key Takeaways

- The Roadshow is a collection of interactive activities with a ready-to-run environment for showcasing OpenShift.
- It serves both prospective customers (awareness of value propositions) and existing customers (deeper feature enablement).
- Three positioning options give presenters flexibility: full-day workshop, regional event, or individual module sessions.

No cluster access is required for this module. All content is informational and delivered through the Showroom interface.
