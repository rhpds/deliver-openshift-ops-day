= ocp4_workload_rhacs - Deploys RHACS

== Recent Updates

*ocp4_workload_rhacs_enable_route_certs*: true::
To avoid browser cert nag screens, this adds the Stackrox CA cert to the Route for Central.

*ocp4_workload_rhacs_central_image_override*: empty by default::
Optionally points the Central deployment at a custom, version-matched image. The role applies this using a Central Operator overlay; confirm the installed Central CRD supports overlays. The image must already be available to the cluster. A draft source patch for the 4.11.4 login-screen metadata polling issue is in `files/patches/metadata-provider-pause-on-error-4.11.4.patch`. It pauses the timer after a metadata request error (including the observed 403) and avoids scheduling another request while one is in flight. The expected recovery is a fresh authenticated app load; confirm the login flow reloads the app before adopting the patch. Because it pauses on any query error, a transient error also requires a page reload to resume polling. Apply it to a matching RHACS source tree and build/publish a private image before setting this variable. The patch and image build have not been validated here, and the role does not build or publish the image. Remove the override when the fix is included in an RHACS release.

== Role overview

* This role installs the following onto the cluster:
** Red Hat Advanced Cluster Security RHACS
** OpenShift Pipelines - to run the plugins
** Sample applications

* It consists of the following tasks files:
** Tasks: link:./tasks/pre_workload.yml[pre_workload.yml] - Sets up an environment for the workload deployment.
*** Debug task will print out: `pre_workload Tasks completed successfully.`

** Tasks: link:./tasks/workload.yml[workload.yml] - Used to deploy ACS
*** This role deploys ACS
*** Debug task will print out: `workload Tasks completed successfully.`

** Tasks: link:./tasks/post_workload.yml[post_workload.yml] - Used to
 configure the workload after deployment
*** This role doesn't do anything here
*** Debug task will print out: `post_workload Tasks completed successfully.`

** Tasks: link:./tasks/remove_workload.yml[remove_workload.yml] - Used to
 delete the workload
*** This role uninstalls ACM and related resources
*** Debug task will print out: `remove_workload Tasks completed successfully.`

* A variable *silent=True* can be passed to suppress debug messages.
